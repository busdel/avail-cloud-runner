Bring your own GPU / server

Your data goes directly from this browser to your machine. The AVAIL server never receives or stores it, and our GPUs are never exposed.

How it works. Run the worker on your own machine, keep it bound to 127.0.0.1, and expose it with your own HTTPS tunnel (Tailscale, Cloudflare, ngrok). Paste the tunnel URL and worker token below; the ZIP is uploaded straight to your worker from this page.

1. Start the worker (on your machine)

pip install -U avail-omics
avail-omics worker-token          # create/print the bearer token
avail-omics worker --name my-gpu  # serves on http://127.0.0.1:8787

Expose it over HTTPS with an outbound-only tunnel, for example:

tailscale serve --bg 8787
# or: cloudflared tunnel --url http://localhost:8787
# or: ngrok http 8787

2. Send a dataset

Do not upload patient identifiers or personal health data. Use de-identified/derived features; you control the receiving machine and its logs.
