{{ icon('monitor','ic') }} Run on my own server

Connect a machine you control. Either install the worker once (pip install avail-omics + avail-omics worker) or simply use the downloaded local runner: python run_me.py --serve (thin launcher: installs the public package into a private venv on first run, then prints a token and binds to 127.0.0.1). The data ZIP is sent directly from this UI to your machine; the token authorizes it.

Sensitive data? Use your own local copy of this interface (or the CLI) instead of the hosted one, so nothing transits maintainer infrastructure.
